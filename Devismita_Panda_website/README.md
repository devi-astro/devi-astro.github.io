# Devismita Panda — Personal Academic Website

A responsive GitHub Pages website for an astrophysics/astrochemistry researcher.

## Files
- `index.html` — complete website
- `assets/portrait.jpg` — enhanced portrait from the supplied image
- `assets/Devismita_Panda_CV.pdf` — add your CV here
- `README.md` — deployment instructions

## GitHub Pages
Create a public repository named `<your-github-username>.github.io`, upload these files, then enable Pages from:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

GitHub will publish the site at `https://<your-github-username>.github.io/`.
